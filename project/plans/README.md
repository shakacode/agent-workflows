# Technical Implementation Plans

This archive holds public technical implementation plans for contributors and
maintainers. A plan can describe active work or completed work.

Plans are point-in-time records. They are not a live source of truth for
current behavior. Executable tests must assert current code, stable fixtures,
or maintained architecture contracts. Tests must not read plan prose as an
executable fixture.
